Cadonix

Apr 2022 – Jul 2026, Chennai
  1. Head of Engineering 2022

I was the first engineer on smartBuild, a manufacturing execution system for formboard assembly and production tracking. I started it from an empty repository in 2023, and it grew to seven services running in production in the cloud. I was responsible for the backend, database, cloud, deployment, security, monitoring and AI features, and I led a team of 8+ engineers across backend, frontend and QA automation.

How it is built
17 repositories of Python and TypeScript. A FastAPI backend on EdgeDB, organised by business domain, with Celery workers, an MQTT service that controls the stations, a central log service, a Nuxt 3 frontend and an Nginx router in front.
Security
I moved 15+ domains to EdgeDB's per-customer isolation, so one customer can no longer reach another customer's data by changing an ID in a request (IDOR bugs). I also designed the login system: JWT with multiple sessions and token revocation, a forced re-login when someone gets more permissions, HSTS, and rate limiting at the WAF.
Cloud
I wrote and ran all of the AWS infrastructure myself, in Pulumi: EC2, IAM with minimal permissions, S3, load balancers, WAF, RDS and ElastiCache, for development, staging and production. Developers could run the whole system on their own machine in 7 Docker containers set up like production, with nothing mocked.
Releases
70+ versioned releases, each moving from feature branch to dev, staging and then production. I wrote the CI/CD pipeline for every service, and a Python command-line tool that handles git, starting and stopping services, releases and database tasks across all 17 repositories.
AI features
An LLM analyses build sequences and streams its answer to the browser over SSE, through Valkey pub/sub, with prompt history, checks that keep questions on topic, and token-cost tracking. I also built an AI agent that reviews merge requests. It can dig through the code over several turns, switches to another model if one fails, and runs from the release tool.
Factory floor
I led the MQTT service that talks to the machines on the shop floor in real time. I gave the station screens their own separate JWT login, and fixed the WebSocket reconnect bugs that broke station pairing.
Logs and alerts
Each service used to log through its own queue. I replaced that with one log service: services send logs to it over HTTP, it sorts them, and alerts go to Slack or email. I kept an incident log and wrote playbooks for the alerts.
